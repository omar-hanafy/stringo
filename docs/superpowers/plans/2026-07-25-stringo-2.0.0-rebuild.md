# stringo 2.0.0 Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild stringo on a shared allocation-free word scanner with an ASCII fast path, fixing eight behavior defects and delivering 7x to 14x throughput without adding a dependency.

**Architecture:** One tokenizer engine (`scanWords`) emits `(start, end)` boundary pairs and allocates nothing. Implementation lives in `lib/src/ops/*` as top-level functions. Two peer facades sit over the ops: the `Stringo` namespace class and the extension set. Neither facade contains logic.

**Tech Stack:** Pure Dart, SDK `^3.10.0`, `dart:core` and `dart:convert` only. Tests via `package:test`.

## Global Constraints

- **Zero dependencies.** `pubspec.yaml` must not gain a `dependencies:` block. Only `dart:core` and `dart:convert`.
- **Pana must stay 160/160.** Every public member needs a doc comment (`public_member_api_docs` is enforced). Formatting must be clean.
- **No `RegExp` construction inside any function body.** Patterns are lazily-initialized top-level `final`.
- **Never use the `—` character** in any file. Use `-` or `_`.
- **Scope rule holds.** No validators (`isValidEmail`, `isUuid`, MIME checks). stringo transforms text; it does not judge real-world validity.
- **Extension names stay unprefixed:** `StringCaseExtensions`, `NullableStringCaseExtensions`, `StringTransformExtensions`, `NullableStringTransformExtensions`, `StringChecksExtensions`.
- **Validation gates** (all must pass before any task is complete):
  ```bash
  dart format --output=none --set-exit-if-changed .
  dart analyze .
  dart test
  ```
- Spec of record: `docs/superpowers/specs/2026-07-25-stringo-2.0.0-performance-rebuild-design.md`

```dart
/// Code-unit classification primitives shared by the scanner and the ops.
///
/// All predicates operate on UTF-16 code units, never on characters, and
/// never allocate.
library;

/// Whether [codeUnit] is whitespace under the ECMAScript `\s` definition.
///
/// This is deliberately the same set that stringo 1.0.0 matched via
/// `RegExp(r'\s')`, so whitespace handling is unchanged for non-ASCII input.
@pragma('vm:prefer-inline')
bool isWhitespaceUnit(int codeUnit) {
  if (codeUnit == 0x20) return true;
  if (codeUnit < 0x09) return false;
  if (codeUnit <= 0x0D) return true;
  if (codeUnit < 0xA0) return false;
  if (codeUnit == 0xA0 || codeUnit == 0x1680) return true;
  if (codeUnit >= 0x2000 && codeUnit <= 0x200A) return true;
  return codeUnit == 0x2028 ||
      codeUnit == 0x2029 ||
      codeUnit == 0x202F ||
      codeUnit == 0x205F ||
      codeUnit == 0x3000 ||
      codeUnit == 0xFEFF;
}
```

Plus `isAsciiLower`, `isAsciiUpper`, `isAsciiDigit`, `isWordSeparator`, `isAsciiString`, each `@pragma('vm:prefer-inline')` and each with a doc comment.

### Task 2: The word scanner engine

**Files:**
- Create: `lib/src/word_scanner.dart`
- Test: `test/word_scanner_test.dart`

**Interfaces:**
- Consumes: `lib/src/chars.dart`.
- Produces:
  ```dart
  void scanWords(String s, void Function(int start, int end) emit);
  List<String> scanWordsToList(String s);
  ```

Boundary rules, preserving 1.0.0's regex `(?<=[a-z])(?=[A-Z])|[_\-\s]+|(?<=[A-Z])(?=[A-Z][a-z])`:
1. zero-width split between ASCII lower and ASCII upper
2. a consumed run of `_`, `-`, or whitespace
3. zero-width split between ASCII upper and (upper followed by lower)

**Behavior change from 1.0.0 (spec defects 2 and 8):** the scanner never emits an empty word. `''` emits nothing, `'  a  '` emits only `a`.

```dart
@pragma('vm:prefer-inline')
void scanWords(String s, void Function(int start, int end) emit) {
  final n = s.length;
  var start = 0;
  var i = 0;
  while (i < n) {
    final c = s.codeUnitAt(i);
    if (isWordSeparator(c)) {
      if (i > start) emit(start, i);
      var j = i + 1;
      while (j < n && isWordSeparator(s.codeUnitAt(j))) {
        j++;
      }
      start = j;
      i = j;
      continue;
    }
    if (i > 0) {
      final p = s.codeUnitAt(i - 1);
      if ((isAsciiLower(p) && isAsciiUpper(c)) ||
          (isAsciiUpper(p) &&
              isAsciiUpper(c) &&
              i + 1 < n &&
              isAsciiLower(s.codeUnitAt(i + 1)))) {
        if (i > start) emit(start, i);
        start = i;
      }
    }
    i++;
  }
  if (n > start) emit(start, n);
}
```

```dart
import 'package:stringo/stringo.dart';
import 'package:test/test.dart';

/// Median of repeated timings, to blunt scheduler noise.
int _medianNanos(int reps, void Function() body) {
  final samples = <int>[];
  for (var i = 0; i < 200; i++) {
    body();
  }
  for (var s = 0; s < reps; s++) {
    final sw = Stopwatch()..start();
    for (var i = 0; i < 50; i++) {
      body();
    }
    sw.stop();
    samples.add(sw.elapsedMicroseconds);
  }
  samples.sort();
  return samples[samples.length ~/ 2];
}

void main() {
  test('isBlank is O(1), not O(length)', () {
    final short = 'x' * 10;
    final long = 'x' * 10000000; // 10 MB
    final tShort = _medianNanos(21, () { short.isBlank; });
    final tLong = _medianNanos(21, () { long.isBlank; });
    // A correct implementation reads one code unit regardless of length.
    // Generous factor: this fails by ~5 orders of magnitude on 1.0.0.
    expect(tLong, lessThan((tShort + 1) * 20),
        reason: 'isBlank appears to scan the whole string; '
            'short=${tShort}us long=${tLong}us');
  });

  test('blank detection short-circuits at the first non-space', () {
    final leading = 'x' + (' ' * 10000000);
    final t = _medianNanos(21, () { leading.isBlank; });
    expect(t, lessThan(2000), reason: 'took ${t}us; expected immediate return');
  });
}
```

```dart
import 'dart:io';
import 'package:test/test.dart';

void main() {
  test('no RegExp is constructed inside a function body in lib/', () {
    final offenders = <String>[];
    for (final f in Directory('lib').listSync(recursive: true).whereType<File>()) {
      if (!f.path.endsWith('.dart')) continue;
      final lines = f.readAsLinesSync();
      for (var i = 0; i < lines.length; i++) {
        final line = lines[i];
        if (!line.contains('RegExp(')) continue;
        final trimmed = line.trimLeft();
        // Allowed: a top-level or static `final ... = RegExp(...)` declaration.
        final isDeclaration = RegExp(r'^(final|static final|const)\s').hasMatch(trimmed);
        if (!isDeclaration) offenders.add('${f.path}:${i + 1}: $line');
      }
    }
    expect(offenders, isEmpty,
        reason: 'RegExp must be hoisted to a top-level final:\n'
            '${offenders.join('\n')}');
  });
}
```
